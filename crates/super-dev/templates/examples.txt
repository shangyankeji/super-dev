Super Dev — common workflows
============================

★ First-time use (recommended)
-------------------------------
    super-dev init                            # scaffold workspace (design systems + templates)
    super-dev                                 # launch the chat TUI
                                              # first time: pick from 11 workers
                                              # then /design modern-minimal (optional)
                                              # type your requirement → pipeline runs
                                              # at each gate press 'c' (or /continue)
                                              # done → release/proof-pack-*.zip

★ Inside the TUI — chat & slash commands
----------------------------------------
    just type            send as a fresh requirement (or revision if a
                         gate is open)
    /claude /codex       switch the worker (saves to ~/.super-dev/config.toml)
    /offline             switch to deterministic templates (demo / CI)
    /continue            approve the active gate
    /revise <text>       stay at gate, request changes
    /spec                show the full SUPER_DEV_HOST_SPEC_V1 spec
    /verify              workspace conformance report
    /doctor              self-test (binary + manifest + probes)
    /diff [name]         show an artifact (default: prd)
    /history             show the full conversation history
    /init                write super-dev.yaml manifest
    /clear               clear chat history
    /help or F1          help overlay (all keybindings)
    /quit or Esc         exit (workflow state is saved)

★ TUI keys
----------
    ↑↓ in palette       cycle slash-command matches
    Tab                 autocomplete the selected slash command
    ↑↓ in empty input    recall previous prompts (100-entry history)
    Shift+Enter         insert a newline (build multi-line prompts)
    ← →                 move cursor character-by-character
    Home / End          jump cursor to start / end
    Backspace / Delete  delete before / at cursor (CJK-safe)
    Esc (when overlay)  close overlay
    Esc (twice)         confirm quit while a pipeline is running

★ Scripted / CI form (no TUI)
------------------------------
    super-dev init                            # write super-dev.yaml manifest
    super-dev run "做一个登录系统" \
                --backend claude-code         # drive Claude Code (no API key)
    super-dev continue                        # approve docs_confirm (auto-reuses --backend)
    super-dev continue                        # approve preview_confirm
    super-dev verify                          # final workspace state + worker
    super-dev report                          # SD-EVID-004 compliance map

    # explicit worker override at any continue (rarely needed):
    super-dev continue --backend claude-code  # force Claude Code for this block
    super-dev continue --backend codex        # switch worker partway through

★ Iterating at a gate (scripted)
--------------------------------
    super-dev revise "把 OAuth 那段去掉,先做 MVP"
    # re-run last block, then:
    super-dev continue                        # once happy

★ Switching the worker mid-conversation (TUI)
----------------------------------------------
    /claude                                   # Anthropic Claude Code
    /codex                                    # OpenAI Codex
    /gemini (or /antigravity)                 # Google Gemini / Antigravity
    /droid                                    # Factory.ai Droid
    /opencode                                 # OpenCode (open source)
    /cursor                                   # Cursor Agent (headless)
    /qwen                                     # Alibaba Qwen Code
    /continue-cli                             # Continue (cn)
    /copilot                                  # GitHub Copilot CLI
    /aider                                    # Aider --message mode
    /trae                                     # ByteDance Trae Agent
    /plandex                                  # Plandex (2M token context)
    /cody                                     # Sourcegraph Cody
    /offline                                  # templates only

★ Inspecting state (no TUI needed)
-----------------------------------
    super-dev verify                          # workflow state + evidence chain
    super-dev doctor                          # binary / workspace self-test
    super-dev spec --clauses                  # the 25-clause table

★ Environment overrides
-----------------------
    SUPER_DEV_CLAUDE_BIN          path to the `claude` binary       (default: claude)
    SUPER_DEV_CLAUDE_PRINT_FLAG   non-interactive flag for claude   (default: --print)
    SUPER_DEV_CODEX_BIN           path to the `codex` binary        (default: codex)
    SUPER_DEV_CODEX_EXEC_SUBCMD   non-interactive sub-command       (default: exec)
    SUPER_DEV_VERIFY_TIMEOUT_SECS verify-loop per-call timeout      (default: 120)
    XDG_CONFIG_HOME               base for super-dev/config.toml    (default: $HOME)
